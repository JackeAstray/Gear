### P1｜文本标签作用域（`<wave>` / `<rainbow>` 等）

- 现状：`GearTextEffects` 是整段文本统一动效，没有按 `<tag>` 分段。
- 做法：`ITextPreprocessor`（TMP）解析标签 → 映射到字符区间 → `ApplyExtraPass` 按区间取参数；
  无标签时保持原样；解析失败回退原始文本。
- **必须先确认** `LanguagesSystem` 的翻译预处理顺序，避免标签被翻译破坏。
- 验收：同一句里混合两种标签、嵌套/未闭合标签、翻译后仍生效。

### P2｜InkPanel 的 RT 烘焙（真正遮子树）

- 现状：`GearInkPanel` 只乘 ImageEx 自身 alpha，**不遮子物体**。
- 做法：把墨团覆盖度渲染到一张 RT（按 Canvas 分辨率/缩放池化），交给 `GearSoftMask` 作为遮罩；
  处理分辨率变化、暂停、销毁释放。
- 验收：卡片内多个子元素同时按墨迹揭开；RT 不泄漏、不每帧重建。

### P3｜可选：展厅 / 3C / 主题

- 展厅按 [第二轮文档](Evo对照-第二轮-渲染契约与模块复刻清单.md) 4.7 的 catalog + 详情窗口方案，不要单场景堆对象。
- 3C 收尾（雷达图 / 点击钻取 / 数据联动）见 [下一阶段规划](Gear-UI-下一阶段开发规划.md) 执行记录末尾。
- 主题注册表 / Style Page 继续缓：先量材质池收益，别在没有 draw call 数据时做。

## 4. 已知坑与约定（务必先读）

1. **文件行数守卫**：单文件 >600 行会挂 `ArchitectureGuardTests`。
   要么拆 partial，要么把新行数写进
   `Assets/Gear/Editor/Toolbox/Guards/file-size-baseline.txt`（基线只能变大一次，之后只能变小）。
2. **画廊卡是增量生成**：新增卡用 `AddCardIfMissing`；改已有卡的生成代码后，老卡不会自动更新，
   需要删卡再跑增量菜单，或全量重建（会清空手工调整）。
3. **保存场景**：正常 Ctrl+S / 编辑器代码 `EditorSceneManager.SaveScene` 都可以；
   **不要用 MCP 的 `manage_scene save`**（曾生成重复的 `Assets/UI Example.unity`）。
4. **EditorSettings 会被 Unity 改写**：进 Play 后 `ProjectSettings/EditorSettings.asset` 经常变脏，
   提交前 `git checkout -- Unity/Gear/ProjectSettings/EditorSettings.asset`。
5. **Inspector 即时预览**：效果组件的 `OnValidate` 里要 `GetComponent<ImageEx>()` 并 `ApplySettings()`，
   进度类字段要序列化；否则"调数值没效果"。相关组件已统一处理，新组件照此办理。
6. **Cover vs 保持纵横比**：Cover 按设计覆盖 `preserveAspect`；Fit 才等价于勾选保持纵横比。
7. **材质池默认关**：`MaterialMode` 默认 Dynamic；Pooled 只给设置稳定的界面，逐帧改 uniform 的实例不要切。
8. **循环动效卡**：`GearAnimatedContainer` 需要 `Loop` 才会持续演示；`GearRectSway` 有 `MaxAngle` 与预览内缩。
9. **EditMode 没有生命周期**：测试里显式 `Bind()` / `ApplySettings()` / `Step()`，不要依赖 `OnEnable` 时序。
10. **LF/CRLF 警告**：git 的 `text=auto` 会在提交时提示 LF→CRLF，属正常，不影响构建。
11. **字体图集**：TMP 字体是 **Dynamic**（`m_AtlasPopulationMode=1`，但关闭了 Multi Atlas）。
    新增中文卡面会自动补字形，同时 `SourceHanSansCN-Regular SDF.asset` 变脏，需要一起提交；
    若图集容量耗尽则会显示方块，需要扩容或开启多图集。
12. **许可红线**：Evo 是商业资产，只做行为级 clean-room；不要复制其源码/着色器/预制体/贴图/字体。
