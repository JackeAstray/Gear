# 2.0 迁移指南（破坏性变更）

> 2.0 收口的是**一致性**问题：命名惯例、命名空间归属、文件名与类型名一致。
> 不改也能跑，但和 .NET / Unity 的约定不一致，会持续误导调用方 —— 所以集中在一次大版本里做完。
>
> 迁移方式统一是「改名 + 加/删 using」，没有语义变化。**唯一需要留神的是 1.3.1 引入的
> 加密帧线格式变更**（`NetworkProtocol.Version = 3`）：那是 1.3.1 起的破坏性变更，
> 客户端与服务端必须同步升级，否则握手阶段即被拒绝。

## 1. 公开成员改 PascalCase

### 1.1 系统初始化标志（14 个系统）

| 旧 | 新 |
|---|---|
| `system.isInited` | `system.IsInited` |

涉及 `AddressableSystem` / `EventMessageSystem` / `LanguagesSystem` / `PauseSystem` / `ResourcesSystem` /
`SceneSystem` / `SoundSystem` / `TerminalSystem` / `UIInputSystem` / `UISystem` / `HttpMgr` / `DownloadMgr` /
`NetworkMgr` / `TimerMgr`。

### 1.3 `Timer`

| 旧 | 新 |
|---|---|

## 2. 接口改名

| 旧 | 新 |
|---|---|
| `UIImgComponent`（`UIImgComponent.cs`） | `IUIImageComponent`（`IUIImageComponent.cs`） |

`.NET` 约定接口用 `I` 前缀；`Img` 缩写没有收益。13 个实现类（`CircleImg` / `HeartImg` / …）只需换接口名。

> 该接口**内部成员**（`sharedMat` / `shouldModifySharedMat` / `rectTransform` / `onComponentSettingsChanged`）
> 仍是 camelCase：它们是 Unity Inspector 里的既有字段名，改名会连带改序列化键、导致已有材质/预制体失联，
> 因此**本轮不动**，留待有迁移工具时再议。

## 3. 命名空间对齐

| 内容 | 旧命名空间 | 新命名空间 |
|---|---|---|
| `Framework/Base/*`（`ICustomSystem`、`IGameEntry`、`ModuleOrderAttribute`…） | `Gear.Framework.Runtime.Base` | `Gear.Base` |
| `Common/Enum/CoreEnum.cs`（`LoaderMode` / `PanelType` / `PanelSize`） | `Gear.Framework.Runtime` | `Gear.Common` |
| `Utilities/UI/TreeView/*` | `Gear` | `Gear.Utilities.UI.TreeView` |
| `Utilities/UI/ButtonExtensions/Click/*` | `Gear.Utilities.UI.ButtonClick` | `Gear.Utilities.UI` |
| `Utilities/UI/ButtonExtensions/Animated/*` | `Gear.Utilities.UI.ButtonAnimated` | `Gear.Utilities.UI` |

迁移：

```diff
-using Gear.Framework.Runtime.Base;
+using Gear.Base;

-using Gear.Utilities.UI.ButtonClick;
+using Gear.Utilities.UI;   // 现在与 ButtonExtensions 其余部分同命名空间，通常已有
```

`Gear.Base` 的程序集名与命名空间此前不一致（程序集 `Gear.Base`，命名空间 `Gear.Framework.Runtime.Base`），
`Gear.Base.asmdef` 的 `rootNamespace` 也已同步改为 `Gear.Base`，新建脚本的默认命名空间随之正确。

TreeView 从 `namespace Gear` 下沉到 `Gear.Utilities.UI.TreeView`：仓库内没有其它消费者，
但**外部工程**若写过 `using Gear;` 引用 `TreeView`，需要改成 `using Gear.Utilities.UI.TreeView;`。

## 4. 文件改名（类型名不变，不影响编译）

| 旧文件 | 新文件 | 主类型 |
|---|---|---|
| `KCPClientChannel.cs` | `KcpClientChannel.cs` | `KcpClientChannel` |
| `KCPServerChannel.cs` | `KcpServerChannel.cs` | `KcpServerChannel` |
| `VertexStream.cs` | `VertexDataStream.cs` | `VertexDataStream` |
| `UIWindowResult.cs` | `WindowResult.cs` | `WindowResult<T>` |
| `UIImgComponent.cs` | `IUIImageComponent.cs` | `IUIImageComponent` |
| `CommonExtensions.cs` | `Extensions.cs` | `Extensions`（`string[]` 扩展） |
| `Type.cs` | `ImageExEnums.cs` | `DrawShape` / `GradientType` / `MaterialMode` / `CornerStyleType` |

Unity 以 `.meta` 的 GUID 关联资源，改文件名（连同 `.meta`）不会丢引用。

## 5. 一次性迁移清单

1. 全局替换 `isInited` → `IsInited`。
2. 全局替换 `using Gear.Framework.Runtime.Base;` → `using Gear.Base;`。
3. 删除 `using Gear.Utilities.UI.ButtonClick;` / `ButtonAnimated;`（若是唯一 using，换成 `Gear.Utilities.UI`）。
4. 按 §1.2 / §1.3 表格替换 `HttpResponse` / `Timer` 成员访问。
5. `UIImgComponent` → `IUIImageComponent`。
6. 编译，剩下未解析的符号基本都是 `Gear.Common`（`PanelType` 等）或 `Gear.Utilities.UI.TreeView` 缺 using。
